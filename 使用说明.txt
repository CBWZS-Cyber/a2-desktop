A2 兴海智学 · 桌面助手  使用说明
================================

一、这是什么
    把 A2 学习中心搬到桌面上：小张常驻桌面右下角，点他一下就进学习中心，
    不用再开浏览器、不用记网址。

二、装完怎么用
    1. 桌面上会出现「A2兴海智学」图标，双击启动。
    2. 第一次启动会直接把学习中心打开一次；以后启动只在右下角出小张，
       点他进学习中心（已经开着就直接切过去，不会开第二个窗口）。
    3. 小张入场会蹦一下，落地后自己说句话。
    4. 按住小张拖动 → 换位置，松手即记住，下次还在原处。
    5. 右键小张 → 菜单：打开学习中心 / 显示桌宠 / 开机自动启动 / 归位 / 关于 / 退出。
    6. 小张周围的透明空白「不挡鼠标」：那块地方可以直接点桌面图标；
       只有小张身上和气泡会接收点击（气泡是实心白块，不让点击穿过去点到后面的图标）。

三、开机自动启动
    右键小张（或托盘图标）→ 勾上「开机自动启动」即可；取消勾选就关掉。
    开机时只会出现小张，不会自动弹学习中心，不打断你。
    卸载时这一项会被自动清掉，不留残迹。

四、关闭与退出
    关掉学习中心窗口 ＝ 只是收起来，小张还在右下角。
    真正退出：右键小张 → 退出（或托盘图标右键 → 退出）。

五、卸载
    设置 → 应用 → 找到「A2兴海智学」→ 卸载；
    或开始菜单 → A2兴海智学 → 卸载 A2兴海智学。
    卸载会删掉程序本体、快捷方式与开机自启项；
    你的本地登录状态与设置保留在 %APPDATA%\A2兴海智学 下，
    要彻底清干净可手动删除该文件夹。

六、常见问题
    1. 提示"连不上服务器"：确认电脑能上网，点窗口里的「重试」；
       也可先用浏览器打开 https://learnest.cn 验证网络。
    2. Windows 提示"未知发布者"：安装包暂未做代码签名，属正常现象，
       点「更多信息 → 仍要运行」；确认来源是本团队提供的安装包再继续。
    3. 小张不见了：看右下角托盘图标，右键 → 显示桌宠小张。
    4. 小张跑到屏幕外了：右键 → 桌宠归位（右下角）。
       换过显示器或改过分辨率后，程序会自动把他拉回可见区域。

七、技术说明
    桌面端只是外壳，学习内容与 AI 能力仍在 learnest.cn 服务端，
    因此需要联网使用；离线时只有小张，进不了学习中心。
