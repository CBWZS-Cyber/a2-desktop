A2 兴海智学 · 桌面助手  使用说明
================================

一、这是什么
    把 A2 学习中心搬到桌面上：小张常驻桌面右下角，点他一下就进学习中心，
    不用再开浏览器、不用记网址。

二、装完怎么用
    1. 桌面上会出现「A2兴海智学」图标，双击启动。
    2. 双击图标就会打开学习中心，同时右下角出小张（已经开着就直接切过去，
       不会开第二个窗口）。只有开机自动启动那一种情况是静默的：
       只出小张，不弹学习中心，不打断你。
    3. 小张入场会蹦一下，落地后自己说句话。
    4. 按住小张拖动 → 换位置，松手即记住，下次还在原处。
    5. 右键小张 → 菜单：打开学习中心 / 隐藏小张 / 开机自动启动 / 归位 / 关于 / 退出。
       鼠标移到小张右上角，会浮出一个小齿轮，点它和右键是同一个菜单。
    6. 小张周围的透明空白「不挡鼠标」：那块地方可以直接点桌面图标；
       只有小张身上、气泡和右上角齿轮会接收点击（气泡是实心白块，
       不让点击穿过去点到后面的图标）。

三、开机自动启动
    右键小张（或托盘图标）→ 勾上「开机自动启动」即可；取消勾选就关掉。
    开机时只会出现小张，不会自动弹学习中心，不打断你。
    卸载时这一项会被自动清掉，不留残迹。

四、关闭与退出
    点学习中心右上角的 × 之后干什么，由「关闭窗口时」决定（默认最小化到托盘）：
      · 最小化到托盘：窗口收起，小张还在右下角，程序继续在后台；
      · 退出程序：窗口和托盘图标一起消失，程序真正结束；
      · 每次询问：每次点 × 都弹框问你要哪个，框里可以勾「记住我的选择」。
    改法：学习中心里点右上角头像 → 账号中心 → 「关闭窗口时」下拉（这个设置只在桌面端有）。
    注意：打开小张那一刻会自动把这一项切回「最小化到托盘」，
    因为一点 × 就把小张一起带走，容易让人以为桌宠自己没了；
    之后你手动选「退出程序」就照你的做，不再拦截。
    不想看见小张：
      · 学习中心里点右上角头像 → 账号中心 → 「显示桌面小张」关掉（这个开关只在桌面端有）；
      · 或者右键小张（或点他右上角齿轮）→ 隐藏小张。
        收起后程序还在托盘里，而且这个选择会被记住，下次开机也不会自己冒出来；
        要叫回来：账号中心重新打开，或右键右下角托盘图标 → 显示小张。
    彻底退出：托盘图标右键 → 退出（或右键小张 → 退出）。

五、下载文件
    学习中心里点「下载 Word」，会弹「另存为」问你存哪里，存到哪就是哪，
    不再把窗口本身顶成一个空白页。存下来的文件可以直接双击打开，
    不会被 Word 拦成「受保护的视图」。

六、卸载
    设置 → 应用 → 找到「A2兴海智学」→ 卸载；
    或开始菜单 → A2兴海智学 → 卸载 A2兴海智学。
    卸载会删掉程序本体、快捷方式与开机自启项；
    你的本地登录状态与设置保留在 %APPDATA%\A2兴海智学 下，
    要彻底清干净可手动删除该文件夹。

七、常见问题
    1. 提示"连不上服务器"：确认电脑能上网，点窗口里的「重试」；
       也可先用浏览器打开 https://learnest.cn 验证网络。
    2. Windows 提示"未知发布者"：安装包暂未做代码签名，属正常现象，
       点「更多信息 → 仍要运行」；确认来源是本团队提供的安装包再继续。
    3. 小张不见了：多半是收起来了。看右下角托盘图标，右键 → 显示小张。
    4. 小张跑到屏幕外了：右键 → 桌宠归位（右下角）。
       换过显示器或改过分辨率后，程序会自动把他拉回可见区域。

八、技术说明
    桌面端只是外壳，学习内容与 AI 能力仍在 learnest.cn 服务端，
    因此需要联网使用；离线时只有小张，进不了学习中心。
